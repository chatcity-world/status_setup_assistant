# 📊 헬프미상태창

SillyTavern 1.19.0 이상에서 쓰는 UI 확장입니다. AI 답변 위나 아래에 상태창을 표시합니다.

## 설치

1. ZIP을 풀면 나오는 `sillytavern-rp-status` 폴더를 **실리태번이 실행 중인 PC 또는 서버**의 `SillyTavern/data/default-user/extensions/`에 넣습니다. 계정 폴더명이 다르면 `default-user`를 해당 이름으로 바꾸세요.
2. `SillyTavern/data/default-user/extensions/sillytavern-rp-status/manifest.json`에 파일이 있는지 확인하고 실리태번 페이지를 새로고침합니다.
3. 상단 **확장 → 📊 헬프미상태창**을 엽니다.

다른 사람에게 Git 주소로 배포하려면 이 폴더 안의 파일들을 저장소 최상위에 올리면 됩니다. 받는 사람은 **확장 → Install extension**에 그 저장소 주소를 넣으면 됩니다.

## 사용

| 위치 | 할 수 있는 일 |
| --- | --- |
| 확장 → 📊 헬프미상태창 맨 위 | **상태창 사용**으로 현재 편집 중인 설정의 메시지 표시와 AI 자동 갱신을 함께 켜고 끕니다. |
| 확장 → 📊 헬프미상태창 → 설정 범위 | **공통** 또는 **캐릭터별**을 선택합니다. **캐릭터별**에서는 저장된 상태창을 고를 수 있습니다. |
| 확장 → 📊 헬프미상태창 → 표시 | **AI 메시지마다 / 상태가 바뀔 때만**, **AI 메시지 위 / 아래**를 선택합니다. |
| 확장 → 📊 헬프미상태창 → 항목 | 항목마다 카드 하나에서 표시 이름, 형식, 표시 여부와 선택 입력인 **AI 작성 규칙**을 설정합니다. 게이지는 0~100입니다. |
| 확장 → 📊 헬프미상태창 → 테마 코드 | **화이트** 또는 **다크**를 고르고 **배치·색상**에서 라벨, 순서, 그룹, 정렬과 색을 바꿉니다. **직접 만들기**로 테마를 생성하거나 HTML을 편집할 수도 있습니다. 미리보기를 확인한 뒤 **저장 및 적용**을 누르면 채팅에 반영됩니다. |

배치·색상은 화이트와 다크에 각각 저장됩니다. 단독 항목은 자기 배경과 글자색을, 그룹은 함께 쓰는 배경과 글자색을 설정합니다. 새 텍스트 항목은 기본적으로 장소·옷차림이 있는 그룹 3에 추가됩니다. 값이 비어 있는 항목은 카드에서 숨깁니다.

테마 생성은 현재 실리태번에 연결된 AI를 사용하며 해당 API 사용량이 발생할 수 있습니다. 생성에 실패하면 기존 코드는 유지됩니다. 새 표시 항목을 저장하면 테마 코드에 해당 항목의 변수도 추가됩니다. `{{항목들}}`을 사용한 테마는 저장한 항목을 자동으로 모아 보여 줍니다.

테마 생성이 안 되면 먼저 일반 채팅에서 답변이 오는지 확인하세요. 채팅도 안 되면 실리태번의 API 연결을 확인하고, 채팅은 되면 **테마 생성** 버튼 아래 안내를 확인하세요. 생성된 테마는 모델의 원본 답변에서 읽어서 채팅 답변에 적용하는 정규식의 영향을 받지 않습니다.

테마 변수는 **항목 저장**을 누르면 표시 이름에 맞춰 만들어집니다. 공백은 `_`로 바뀌고, 같은 변수 이름이 이미 있으면 숫자가 붙습니다. 변수는 **테마 코드 → 사용할 수 있는 변수**와 새로 생성한 테마 코드에서 확인할 수 있습니다. 이름을 바꾼 뒤에도 기존 채팅의 값과 이전 테마 변수는 이어서 읽습니다. 기존 버전의 분리된 CSS는 업그레이드 시 코드 박스의 style 블록에 합쳐지며, 새로 생성되는 테마는 인라인 style을 사용합니다.

**AI 작성 규칙**에는 예를 들어 날짜는 “YYYY년 MM월 DD일”, 속마음은 “한 문장 이내”라고 적을 수 있습니다. 표시가 켜진 항목의 비어 있지 않은 규칙만 채팅의 AI 요청에 포함됩니다. 규칙은 AI가 값을 작성할 때 참고하며, 확장이 기존 값의 형식을 변환하지는 않습니다.

기본 항목은 날짜, 시간, 날씨, 기온, 장소, 옷차림, 호감도, 속마음입니다. 각 항목에는 AI 작성 규칙이 들어 있으며 **항목**에서 수정할 수 있습니다. 작성 규칙의 {{char}}와 {{user}}는 AI에 보낼 때 현재 캐릭터와 사용자 이름으로 바뀝니다. 호감도는 0~100 게이지로 표시합니다.

기본 항목과 테마를 쓰던 설정은 새 기본값으로 바뀝니다. 기존 `애정` 값은 호감도로 이어서 읽고, 호감도 항목의 변수는 `호감도`로 표시합니다. 실제 값은 채팅별로 저장되며 답변 후보를 바꾸면 해당 후보의 상태를 다시 계산합니다.

## 캐릭터별 설정

1. 상태창을 저장할 캐릭터의 1:1 채팅을 엽니다.
2. **확장 → 📊 헬프미상태창 → 캐릭터별**에서 현재 채팅의 캐릭터 이름을 확인하고 **상태창 저장**을 누릅니다. 처음 저장할 때 공통 설정을 복사합니다.
3. **저장된 캐릭터** 메뉴에서 편집할 상태창을 고른 뒤 **표시**, **항목**, **테마 코드**를 설정합니다.

캐릭터마다 전용 설정 하나를 저장하며, 같은 캐릭터의 새 채팅과 기존 1:1 채팅에 적용됩니다. 목록 옆 **삭제**를 누르고 이름을 확인하면 해당 전용 설정이 목록에서 빠지고 공통 설정이 적용됩니다. 그룹 채팅도 공통 설정을 사용합니다.

전용 설정은 실리태번 계정의 확장 설정에 저장됩니다. 캐릭터 카드를 내보낼 때 함께 포함되지 않습니다. 이전 버전에서 적용을 끈 설정은 그 캐릭터의 1:1 채팅을 열고 **상태창 저장**을 누르면 다시 불러옵니다.

## HTML 변수

HTML의 태그 사이에 변수를 넣으세요. 예를 들어 `<p>장소 · {{장소}}</p>`는 장소만 표시합니다. `{{항목들}}`은 값이 있는 표시 항목을 한 번 모아 표시합니다. 항목의 이름과 값은 나란히 배치되고 공간이 부족하면 줄바꿈됩니다. 게이지 형식으로 저장한 항목에는 값과 막대 변수가 함께 생깁니다. 예를 들어 `{{신뢰도}}`는 숫자를, `{{신뢰도_게이지}}`는 막대를 표시합니다. 상태창에 넣을 스타일은 HTML 태그의 style 속성에 작성합니다.

커스텀 테마에서 `{{표시:호감도}}`를 쓰면 항목의 저장된 형식에 따라 텍스트 또는 게이지와 퍼센트가 표시됩니다. 값이 들어오기 전에는 `—`가 표시됩니다. 호감도 항목 하나를 `호감도` 또는 `애정` 키로 쓰던 테마와 채팅을 모두 읽을 수 있습니다.

채팅 상태창의 바깥선은 본문 문단의 양쪽 안쪽 여백에 맞춰집니다. 기본 테마는 첫 항목부터 표시하며, 이전 테마에 들어 있는 ‘상태창’ 제목도 화면에서 생략합니다.

## AI 자동 갱신

**상태창 사용**을 켜면 실리태번이 현재 상태값과 갱신 형식을 AI에 전달합니다. 응답 끝에 아래와 같은 블록이 오면 변경된 키만 반영합니다. 블록은 확장이 켜진 실리태번의 답변 화면에서 숨겨집니다.

```text
[[RP_STATUS]]
{"장소":"타로점","기온":"12°C","호감도":42}
[[/RP_STATUS]]
```

기존 값은 새 값이 들어올 때까지 이어집니다. 응답에 유효한 블록이 없으면 상태는 그대로입니다. 자동 갱신은 사용 중인 모델이 이 형식을 따를 때 작동합니다.
